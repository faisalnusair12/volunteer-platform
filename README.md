# Volunteer Platform

ASP.NET Core full-stack volunteering platform project.

## Features
- User authentication and authorization
- Volunteer task management
- Organization management
- Admin dashboard
- Reviews and tags system
- File/image uploads
- RESTful API endpoints

## Technologies Used
- ASP.NET Core
- Entity Framework Core
- SQLite
- JWT Authentication
- React / Vite
- Swagger

## Status
Project is under continuous development and improvement.
